# דוד

שלט לדוד חכם של סוויץ׳ר (V2, V4, Touch, Mini), שמדבר עם הדוד ישירות ברשת ה-WiFi של הבית.

- טיימר בחוגה, זמנים מהירים, הוספת זמן והדלקה ללא טיימר
- כיבוי אוטומטי ותזמונים (כולל השבתה זמנית)
- Live Activity ו-Dynamic Island עם ספירה לאחור
- ווידג׳ט למסך הבית ולמסך הנעילה
- Siri וקיצורי דרך: "הדלק את הדוד ל-30 דקות"
- התראה כשהחימום נגמר, וסטטיסטיקת צריכה בשקלים

## בנייה

כל push ל-`main` מריץ את הבדיקות ובונה `Dud.ipa` ב-GitHub Actions. הקובץ מופיע ב-Releases, ומתקינים אותו עם Sideloadly.

## מציאת פרטי הדוד מהמחשב

אם האפליקציה לא מוצאת את הדוד לבד, מריצים במחשב שמחובר לאותה רשת:

```
python tools/discover.py
```

הסקריפט מדפיס את כתובת ה-IP, מזהה המכשיר והמפתח.

הפרוטוקול מבוסס על הספרייה הפתוחה [aioswitcher](https://github.com/tomerfi/aioswitcher) (Apache-2.0).
